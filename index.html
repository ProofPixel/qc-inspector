☁ Cloud sharing

Optional. Connect a free Supabase project so rules and the library are shared with everyone who opens the online app. Only the admin (Supabase login) can change them. Without it, everything stays in this browser.

Quick setup: 1) Create a Supabase project. 2) Copy its Project URL and anon/public key into the fields. 3) Click Copy SQL setup, open Supabase → SQL Editor, paste and Run. 4) Create one admin in Authentication → Users and turn off public sign-ups. 5) Click Save & connect, then Admin login. Start with a test project and verify its RLS policies before using real client rules.

🔗 Photoshop Link & Settings

Windows setup – required for QC fixes and direct JSX script launch. After updating this app, run the setup again to refresh the handler.
1
Copy the setup command
Start menu → type PowerShell → open it → right-click inside the window (paste) → press Enter. Wait for the green "installed" message. No file is downloaded, so Windows cannot block it.
2
Test the link
Photoshop should show "QC Inspector link works!". If Chrome asks to open the app, tick Always allow.
Prefer a file? Download the .bat instead — if Windows says "These files can't be opened": right-click the file → Properties → tick Unblock → OK, then run it.
